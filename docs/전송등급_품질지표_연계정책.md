# J-01-1 전송 등급 정의 ~ K-01 품질지표 연계 정책

## J-01-1 전송 등급 정의

- 전송 등급(Tier)은 병원별 데이터 전송 신뢰도를 계량화한 운영 등급이다.
- 등급 산정 시 필드 충족률, 누락률, 오류율, 정시전송률을 기본 지표로 사용한다.
- 등급은 Gold / Silver / Bronze / Monitor 4단계로 운영한다.

## J-01-1A 전송 등급-품질지표 연결 규칙

### 1) Tier 산정식 정의

| Tier | 산정식(모든 조건 동시 충족) | 판정 기준 |
|---|---|---|
| Gold | 필수 필드 충족 + 최근 90일 누락률 ≤ 2% + 최근 90일 오류율 ≤ 1% + 최근 90일 정시전송률 ≥ 95% | 최고 안정 구간 |
| Silver | 필수 필드 충족 + 최근 90일 누락률 ≤ 5% + 최근 90일 오류율 ≤ 2% + 최근 90일 정시전송률 ≥ 90% | 목표 충족 구간 |
| Bronze | 필수 필드 충족 + 최근 90일 누락률 ≤ 8% + 최근 90일 오류율 ≤ 4% + 최근 90일 정시전송률 ≥ 85% | 개선 필요 구간 |
| Monitor | 상위 Tier 조건 미충족 또는 필수 필드 미충족 | 집중 모니터링 구간 |

> 보조 규칙: 최근 90일 데이터가 없는 신규 기관은 임시 등급(Provisioning)으로 분류하고, 최소 모수 충족 후 정식 Tier를 부여한다.

### 2) 승급/강등 운영 정책

- 평가 주기: 월 1회(매월 1영업일 00:00 배치 기준) 자동 평가.
- 승급 정책: 산정식 충족 시 차월 즉시 반영.
- 강등 정책: 강등 조건 충족 시 즉시 후보 지정 후 30일 유예기간 부여.
- 유예기간(30일): 유예기간 내 지표가 회복되면 강등 취소, 미회복 시 강등 확정.
- 재심 프로세스:
  1. 병원 또는 운영 담당자가 강등 예정 통지일 기준 7일 이내 재심 요청.
  2. 운영팀은 원시 로그, 장애 이력, 예외 사유를 검토.
  3. 데이터 거버넌스 책임자가 최종 승인/기각.
  4. 승인 시 해당 평가 회차에 한해 강등 보류 또는 지표 재산정.

### 3) 측정 모수 및 예외 케이스

- 최소 모수(표본 수) 기준:
  - 최근 90일 누적 전송 건수 1,000건 이상 또는 월 300건 이상을 등급 판정의 최소 기준으로 한다.
  - 최소 모수 미달 시 등급 유지(동결) 또는 Provisioning/Monitor로 관리하고, 산정식 결과를 참고값으로만 표시한다.
- 예외 케이스 규정:
  - 휴업/폐업/장기 휴진: 사전 등록된 휴업 기간은 정시전송률 분모에서 제외.
  - 시스템 장애(플랫폼/통신): 공지된 장애 시간대의 실패 건은 오류율/정시전송률 산정에서 제외 가능.
  - 외부 정책변경/의무전송 중단: 운영위원회 승인 후 해당 기간 지표를 보정 또는 평가 유예.
- 예외 적용 원칙:
  - 모든 예외는 티켓 번호, 증빙 로그, 적용 기간을 필수 기록.
  - 예외 반영 내역은 감사 로그로 1년 이상 보관.

### 4) Admin 화면 요구사항 (병원별 KPI 근거값 조회)

- 운영자(Admin)는 병원 단위로 Tier 산정 근거 KPI를 조회할 수 있어야 한다.
- 필수 조회 항목:
  - 평가 기간(최근 90일), 총 전송 건수, 필수 필드 충족률
  - 누락률, 오류율, 정시전송률
  - 현재 Tier, 직전 Tier, 승급/강등 후보 상태, 유예 종료일
  - 예외 적용 여부, 예외 사유, 승인자, 티켓 번호
- 화면 기능 요구사항:
  - 병원명/기관코드 검색, 기간 필터, CSV 다운로드
  - 지표별 원시 건수(분자/분모) Drill-down
  - 재심 요청/처리 이력 타임라인

## K-01 품질지표

- K-01은 전송 품질의 결과 지표를 정의하며, J-01-1A의 Tier 산정 입력값과 동일한 원천 데이터를 사용한다.
- K-01 리포트는 월간 Tier 변동, 예외 반영 내역, 재심 처리 결과를 함께 제공한다.
